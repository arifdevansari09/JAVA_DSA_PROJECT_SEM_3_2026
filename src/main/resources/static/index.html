Underlying Data Structures & Complexity Overview

1. HashMap (Product Catalog)

Maps productId → Product. Provides O(1) average time for instant SKU lookups, stock updates, and removals during checkout.

2. Min-Heap Priority Queue

Orders items by quantity ≤ minThreshold. The root element is always the item nearest depletion in O(1) peek time for restock alerts.

3. FIFO Queue (Order Processing)

Queues incoming customer orders in arrival order. Enqueue and Dequeue operations take O(1) time, preventing unfair order skipping.

4. LIFO Stack (Transaction Undo)

Pushes stock state before every modification. Allows warehouse operators to safely Undo mistakes in O(1) pop time.
